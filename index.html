🚀 Kubernetes ਕੀ ਹੈ?

Kubernetes ਇੱਕ open-source container orchestration platform ਹੈ। ਇਹ containers ਨੂੰ deploy, scale, network ਅਤੇ manage ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ।

ਸੌਖੀ example: ਜੇ ਤੁਹਾਡੇ ਕੋਲ 100 application containers ਹਨ, Kubernetes ਉਹਨਾਂ ਨੂੰ ਚਲਾਉਣ, restart ਕਰਨ ਅਤੇ traffic distribute ਕਰਨ ਦਾ ਕੰਮ automate ਕਰ ਸਕਦਾ ਹੈ।

🏗️ Cluster ਦੇ ਮੁੱਖ ਹਿੱਸੇ

Control PlaneWorker NodePodServiceDeployment

Control Plane: cluster ਨੂੰ control ਕਰਦਾ ਹੈ। ਇਸ ਵਿੱਚ API Server, etcd, Scheduler ਅਤੇ Controller Manager ਹੁੰਦੇ ਹਨ।

Worker Node: ਇੱਥੇ application workloads/PODs ਚਲਦੇ ਹਨ। Kubelet ਅਤੇ container runtime ਮਹੱਤਵਪੂਰਨ components ਹਨ।

🔄 Simple Request Flow

User → Load Balancer/Ingress → Service → Pod → Container

Administrator → kubectl → API Server → Scheduler/Controllers → Worker Node

📦 ਪਹਿਲਾ Pod

kubectl run nginx --image=nginx
kubectl get pods
kubectl describe pod nginx
kubectl delete pod nginx

Pod Kubernetes ਵਿੱਚ deploy ਹੋਣ ਵਾਲੀ ਸਭ ਤੋਂ basic workload unit ਹੈ। ਆਮ ਤੌਰ ਤੇ ਇੱਕ Pod ਵਿੱਚ ਇੱਕ ਜਾਂ ਵੱਧ closely-related containers ਹੁੰਦੇ ਹਨ।
